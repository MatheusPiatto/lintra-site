# Site da LINTRA

Site institucional em HTML estático, publicado pelo GitHub Pages em https://lintratech.com.br (arquivo `CNAME`).
Qualquer alteração enviada para a branch `main` vai ao ar em cerca de 1 minuto.

- `index.html` (início), `coachapp.html` (página do produto), `404.html`, `estilo.css`, `site.js`
- **Endereço da área do cliente e WhatsApp:** no topo de `site.js`
- **Instagram:** publicações exibidas vêm de `instagram.json` (cole o link de até 3 posts)
- **Imagens do CoachApp** (`img/`): telas reais com dados de demonstração fictícios
